ui-preview.png — статический визуальный предварительный просмотр веб-интерфейса, отрендеренный из HTML/Jinja-шаблона app.py с результатом Письма_04. Он иллюстрирует макет и отображение позиций/уточнений, но не является снимком браузера, подключённого к живому Flask-серверу или LLM API.

Для проверки интерактивной версии установите зависимости по README.md, внесите OPENROUTER_API_KEY в .env, выполните python app.py и откройте http://127.0.0.1:5000. Скриншот запущенного интерфейса можно сделать в Windows сочетанием Win+Shift+S.
