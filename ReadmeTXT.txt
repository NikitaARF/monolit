В папке уже есть подробный readme, как пользоваться программой.
В данном текстовом документе я покажу как запустить без ИИ и получить данные
1)Скачиваем папку с гитхаба
2)Открываем powershell в папке проекта и запускаем скрипт:
   py -m venv .venv
   .\.venv\Scripts\activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   copy .env.example .env
3)В том же powershell вводим (для Офлайн-проверки и формирование результатов)
python batch.py --no-llm
4)После того как команда сработала открываем папку results в папке проекта и мы сможем
увидеть наши результаты docs-фаилы и json по формату(хочу отметить, когда вы скачаете папку с проектом, там уже будут готовые расчеты, их можно удалить и выполнить команду 3, расчеты будут одни и те же)

P.S. В папке проекта есть AI_USAGE и подробный README, хочу рассказать немного по
подробнее, изначально мы создавали программу под платную ИИ(gpt-4), доступом к таким ресурсам не обладаю, поэтому при использовании openrouter использовался способ подключения бесплатной ИИ модели с помощью LLM_MODEL=openrouter/free из-за этого в заказах где требуется доставка, она иногда считается, а иногда нет, я думаю, что если использовать более подходящую платную ИИ модель, можно этого избежать, так как заказы без доставки соответсвуют нужным результатам.

На скриншотах 1 и 2: 1-скрин с сайта, где мы формируем данные с помощью ИИ. 2-скрин ворд документа, данные формируются без ИИ, как мы видим все сходится.
!НО на скриншотах 3 и 4: если мы возьмем более сложный заказ с доставкой, получаются расхождения, но этого компенсируются подсказками для менеджера, где указано что не учитывалось в конечной стоимости.

P.P.S Данные без ИИ в папке result являются максимально точными
